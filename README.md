# 见微工作台

本地优先的 AI agent 工作台：自动看住 Claude Code、Codex、DeepSeek 的会话，把它们归进项目和任务，用一座会长高的城市展示你的进度。数据只在你的电脑上。

## 下载

到 [Releases](https://github.com/jianwei-app/jianwei-releases/releases) 下载最新版：

- **Mac**：下载 `.dmg`
- **Windows**：下载 `.exe`（即将推出）

## 系统要求

- macOS 13 或更新
- Windows 10 / 11（即将推出）

## 第一次打开（Mac）

正式签名完成前，请在"应用程序"里右键点见微，选"打开"。

## 反馈问题

在 [Issues](https://github.com/jianwei-app/jianwei-releases/issues) 里提。

## 更新

见微会自动检查新版本。
